HOW IT WORKS

나만의 배포, 세 단계면 충분해요.

신뢰하는 프로젝트만 실행하는 개인 관리자용 MVP입니다.

  1. 01
    프로젝트 등록

    프로젝트 루트 내부의 경로와 Dockerfile을 준비하세요.

  2. 02
    이미지 빌드 & 실행

    환경변수를 전달하고, 제한된 리소스로 컨테이너를 실행해요.

  3. 03
    상태·로그 확인

    HTTP 준비 확인 후 로컬 주소를 제공하고 빌드·실행 로그를 남겨요.

서버 정보

서버 설정을 확인하고 있어요.

앱 주소는 서버의 localhost 포트입니다. 외부 공개 도메인·HTTPS는 별도 역방향 프록시 설정이 필요합니다.
